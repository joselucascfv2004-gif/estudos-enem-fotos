# Fotos das questões do ENEM — App Estudos

Fotos dos enunciados das provas oficiais do ENEM (2009 a 2025), recortadas dos cadernos publicados pelo
INEP, sem as alternativas. O App Estudos baixa cada foto na primeira vez que a questão aparece e guarda no
aparelho. Uma pasta por ano; o nome segue `enem-ANO-dDIA-qNUM[-es]-e.webp`.
